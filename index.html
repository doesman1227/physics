01

物理学とは

いちばん少ない約束ごとで、いちばん多くのことを説明する。

物理学は、物と力、エネルギー、空間と時間がどうふるまうかを、数式で表せる法則として探す学問です。観察し、法則を仮説として立て、予言し、実験で確かめる。この繰り返しで、ばらばらに見えた現象が、少数の法則にまとまっていきました。

扱う世界は、大きさと速さで分けると見通しやすくなります。

素粒子→原子→身のまわり→惑星→銀河→宇宙全体

小さい世界では量子力学、速い世界や重い世界では相対性理論、その間ではニュートン力学がよく当てはまる。

ELECTROMAGNETISM電磁気学

電気と磁気は一つのものの二つの顔だった。マクスウェルの方程式は、光が電磁波であることまで示した。

問い：光とは、何が波打っているのか電磁気学のノートへ →
THERMODYNAMICS熱力学・統計力学

熱とエネルギー、そして「乱雑さ（エントロピー）は増えていく」という法則。たくさんの粒子のふるまいを確率で扱う。

問い：なぜ時間は一方向にしか進まないように見えるのか熱力学のノートへ →
RELATIVITY相対性理論

光の速さは誰から見ても同じ。そこから、時間と空間は一体の「時空」で、速さや重力で伸び縮みすることが導かれた。

問い：時間は、宇宙に一つだけある時計ではない相対性理論のノートへ →　時間のノートへ →

03

流れ

  1. 1687ニュートン『プリンキピア』天と地の運動を、同じ法則で説明する。
  2. 1864マクスウェル方程式電気・磁気・光が一つにまとまる。
  3. 19世紀熱力学エネルギーの保存と、エントロピーの増大。
  4. 1905・1915相対性理論時間と空間が、一つの時空になる。
  5. 1925量子力学の誕生ミクロの世界のルールが書き換わる。
  6. 1970年代標準模型物質と力を、素粒子で説明する枠組み。
  7. 2012・2015ヒッグス粒子と重力波予言されていたものが、実際に見つかる。

自分の問い

対称性は、なぜ存在するのか

自然界にはなぜこれほど対称性が現れるのか。それは世界の性質なのか、それとも世界を見る側の性質なのか。まだ問いだけを置いている。

対称性は、なぜ存在するんだろう。 →なぜ世界は釣り合っているのか →

時間は、一律ではなかった

速く動くほど、重力が強いほど、時間はゆっくり進む。本人には普通に流れていて、別の経路をたどった人と時計を比べたときに初めて差が分かる。時間は宇宙に一つだけある絶対の時計ではなかった。

一律ではなく、時空の性質 →

観測とは、何をしているのか

粒子が「消えた」のではなく、広がっていた。結果が「変わった」のではなく、隠れていた。量子の不思議は、どの経路の情報が残るかどうかで決まっているように見える。

経路が残るかどうか、それだけ →変わったのではなく、隠れていた →消えたのではなく、広がっていた →重ね合わせはあるが、干渉はできない →

物理だから単純、ではない

意識も物理現象として説明できる可能性は高い。けれど物理現象であることと、単純であることは別。原子から分子、細胞、神経、情報、自己へと積み上がる階層のどこかで、何かが立ち上がっている。

物理だから単純、ではない →少ない要素から、複雑が生まれる →
